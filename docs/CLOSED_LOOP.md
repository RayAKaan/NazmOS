# Closed Loop

The Day 1 → Day 14 loop, proven by `tests/test_phase12_closed_loop.py`.

- **Day 1** — audit runs, finding created, root-cause investigated (supported/plausible/
  uncertain), strategy ranked (goal + impact + urgency + confidence + data quality +
  historical effectiveness + recency + regime + risk).
- **Day 2** — approval → execution → verification → impact (attributed) → learning.
- **Day 3–4** — recurrence → prior intervention retrieved → learning changes ranking.
- **Day 7** — weekly report with shared deterministic top-N priorities.
- **Day 14** — audit comparison classifies NEW/PERSISTENT/RECURRING; stale/missing data never
  fabricates RESOLVED.

Deterministic at every stage; the LLM never computes scores, impact, policy, or attribution.
