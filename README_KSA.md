# NazmOS Retail Recovery — KSA

NazmOS is a Retail Recovery System by Nazmak.

It helps Saudi retailers find cash trapped in inventory, prevent stockouts, protect margins, approve fixes on WhatsApp, and preview Recovery Match opportunities between nearby stores.

## Core offer

- Free Money Audit
- Dead stock detection
- Stockout risk
- Margin leakage
- Weekly Money Report
- WhatsApp approvals
- Recovery Match preview

## Not in core product

External regulated services are not part of the core product. NazmOS focuses on retail recovery first.

## First wedge

Send two files: sales export and inventory export. NazmOS returns a Money Audit in 48 hours.
