# NazmOS Documentation

Documentation is organized by purpose.

- [Engineering](engineering/) — architecture, contracts, migration/acceptance material.
- [Research](research/) — model, AI and technical research.
- [Strategy](strategy/) — product and business strategy.

- [Archive](archive/) — historical material retained only when it remains useful.
